# qwzwqqe · Chess Panel

Пользовательский скрипт Владислава (qwzwqqe) для разбора позиций на Chess.com. Версия 23.11 использует Stockfish 18 Lite и показывает ход в плавающей пиксельной панели.

## Установка

1. Установите Tampermonkey в браузере.
2. Откройте [qwzwqqe.user.js](./qwzwqqe.user.js) и нажмите **Raw**. Подтвердите установку в Tampermonkey. Если откроется текст, скопируйте его в новый скрипт Tampermonkey и сохраните.
3. Откройте доску Chess.com. После загрузки движка нажмите **Z** (физическая клавиша **Я** в русской раскладке).
4. Перетащите панель мышью или пальцем. Положение сохраняется в браузере.

При загрузке скрипт запрашивает файлы движка с unpkg.com и пиксельный шрифт с fonts.gstatic.com.
